ENVISION - Eye-Tracking & Hand Gesture Game Platform

An innovative gaming platform that combines eye-tracking technology with  hand gesture controls to create an immersive and accessible gaming experience.

 Features

Control Modes
 Control character movement and abilities using gaze tracking
 Use hand gestures for precise control (PINCH, FIST, PISTOL_AIM)
 Traditional keyboard controls as fallback

 Gameplay
- Procedurally generated platformer levels
- Multiple platform types: Moving, Crumbling, Bouncy, Springs
- Collectibles: Coins, Gems, Health Packs
- Enemies: Ground enemies and Flying enemies
- Special abilities: Double jump, Dash, Projectile shooting

 Technical Features
- Real-time eye tracking using MediaPipe
- Hand gesture recognition with MediaPipe
- Custom sprite animation system
- Smart map generation algorithm
- Parallax background system
