This is an assistive eye-tracking adventure game

An eye-tracking adventure game designed for accessibility, allowing players to control gameplay with inputs like eye movements and hand gestures.


-Smart map system with recursive platform generation
-Switch between eye tracking, hand gestures, and keyboard
-character's Double jump, dash, projectile shooting
-aesthetically designed UI
...
